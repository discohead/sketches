## Review Focus

1. **Recorded size differs from the canvas** (Retina scaling, or a canvas larger than the screen): every captured PNG must be exactly `canvas.width × canvas.height` or capture fails loudly with both sizes. Tested in Task 3 and checked in Task 6.
2. **An interrupted hang** (push fails, ffmpeg dies, Ctrl-C): re-running `studio hang` on the same piece resumes with the same catalog number. It never takes a second number and never overwrites an existing deposit. Tested in Task 6.
3. **An ambiguous piece name** (a slug shared by a piece and its variation): `studio` errors and lists the matches. It never picks one silently. Tested in Task 4.
4. **A piece that fails to build, panics, or never exits during capture:** studio shows cargo's or the piece's error output, exits non-zero within a timeout, and leaves no rename and no partial deposit behind. Tested in Tasks 5 and 6.
5. **Hanging an unready piece** (empty title or statement, `audio = true`, `live = true`): refused with a message naming the field and saying sound and live builds are Phase 2. Tested in Task 6.

### Task 6: `studio hang`: record, number, commit, push, deposit

**Files:**
- Create: `tools/studio/src/hang.rs`, `tools/studio/src/deposit.rs`, `tools/studio/src/catalog.rs`; extend `media.rs`
- Create: `docs/deposit-spec.md`
- Test: unit tests in each; `tools/studio/tests/hang_e2e.rs` (ignored)

**Interfaces:**
- Consumes: everything above
- Produces:
  - `catalog::next_number(ws) -> Result<u32>`: the maximum of the numbers in `pieces/dss####-*` folders and `outbox/DSS####` dirs, plus 1. It never fills gaps.
  - `media::encode_master(frames_dir, fps, out)`: `libx264 -preset slow -crf 10 -pix_fmt yuv444p`
  - `media::encode_web(frames_dir, fps, out)`: native canvas, `-crf 18 -pix_fmt yuv420p -movflags +faststart`
  - `media::encode_cut(frames_dir, fps, repeats, w, h, out)`, using the same codec settings as web
  - `media::cut_filter(w, h) -> String`, which equals exactly `scale={w}:{h}:force_original_aspect_ratio=decrease:flags=lanczos,pad={w}:{h}:(ow-iw)/2:(oh-ih)/2:black,setsar=1`
  - `media::loop_repeats(seconds: f32, min_seconds: f32) -> u32`: `max(1, ceil(min_seconds / seconds))` for loops; always 1 for the duration form
  - Cuts, with `min_seconds = 15`: `feed-4x5.mp4` 1080×1350, `reel-9x16.mp4` 1080×1920, `wide-16x9.mp4` 1920×1080
  - `deposit::Deposit` serializes `piece.json`. Field names and shape are exact:

```json
{
  "schema": "dss-deposit/0",
  "catalog": "DSS0001",
  "title": "", "slug": "", "date": "YYYY-MM-DD", "statement": "",
  "tags": [], "series": null, "parent": null,
  "source": { "repo": "https://github.com/<owner>/<repo>", "commit": "<sha>", "path": "pieces/dss0001-<slug>" },
  "canvas": { "width": 1080, "height": 1080 },
  "time": { "fps": 60, "form": "loop", "seconds": 8.0 },
  "live": false, "audio": false,
  "media": [
    { "file": "still.png", "kind": "still", "width": 1080, "height": 1080 },
    { "file": "master.mp4", "kind": "master", "width": 1080, "height": 1080, "seconds": 8.0, "fps": 60, "audio": false },
    { "file": "loop.mp4", "kind": "web", "...": "same fields as master" },
    { "file": "feed-4x5.mp4", "kind": "social", "aspect": "4:5", "...": "same fields, cut size and repeated length" },
    { "file": "reel-9x16.mp4", "kind": "social", "aspect": "9:16" },
    { "file": "wide-16x9.mp4", "kind": "social", "aspect": "16:9" }
  ]
}
```

  `parent` is the parent's catalog id if the parent is hung, otherwise `null`. `date` is the hang date. `repo` comes from `git remote get-url origin`, normalized to `https://github.com/<owner>/<repo>`.
  - `hang::run(ws, name, opts: HangOpts { push: bool }) -> Result<PathBuf>` returns the final deposit dir. Order (each step is skipped if already done, so a re-run resumes):
    1. Resolve. If `readiness_errors()` is not empty, refuse and list them.
    2. Number: reuse `meta.catalog` if set; otherwise `next_number`.
